# 轴承故障诊断算法开发技术报告

## 1. 概述

### 1.1 诊断对象与工况范围
本报告面向**列车滚动轴承故障诊断**。算法适用前提为：
- 工况：转速稳定工况；
- 传感器：加速度振动传感器；
- 采集周期：每 10 分钟采集一组稳定转速数据；
- 诊断目标：内圈故障、外圈故障、滚动体故障、保持架故障。

### 1.2 输入与输出定义
- 输入：
  - 转速（rpm）；
  - 加速度振动时域信号（单位建议：g 或 m/s²）。
- 输出：
  - CI 指标：
    - `RMS`
    - `ENV_BPFI_AMP`（包络谱内圈故障特征幅值）
    - `ENV_BPFO_AMP`（包络谱外圈故障特征幅值）
    - `ENV_BSF_AMP`（包络谱滚动体故障特征幅值）
    - `ENV_FTF_AMP`（包络谱保持架故障特征幅值）
  - 是否告警（Alarm Flag，布尔值）。

### 1.3 阈值与告警规则
- 阈值策略：基于正常样本统计，采用高斯分布假设下的
  \[
  T = \mu + 3\sigma
  \]
- 告警判据：任一目标 CI 指标连续 3 个采样点超限，触发告警。

## 2. 原理

### 2.1 经典轴承故障冲击机理
滚动轴承局部缺陷（内圈/外圈/滚动体/保持架）会在滚动接触过程中产生周期性冲击。冲击会激发结构共振并在振动信号中形成调幅成分。对这类调幅信号进行包络解调后，可在包络谱中观察到与故障特征频率对应的谱线。

### 2.2 包络解调原理
包络解调用于从高频共振载波中恢复低频冲击调制信息，典型流程：
1. 对原始振动信号进行带通滤波，保留冲击激发共振带；
2. 使用 Hilbert 变换构造解析信号并计算包络；
3. 对包络信号做 FFT，得到包络谱；
4. 在 BPFI/BPFO/BSF/FTF 及其倍频附近提取故障特征幅值或能量。

### 2.3 轴承故障特征频率公式
设：
- $f_r$：轴转频（Hz，$f_r = \text{rpm}/60$）
- $n$：滚动体个数
- $d$：滚动体直径
- $D$：节圆直径
- $\theta$：接触角

常用特征频率公式如下：

| 频率类型 | 公式 |
|---|---|
| 内圈故障频率 BPFI | $\text{BPFI} = \frac{n}{2}f_r\left(1+\frac{d}{D}\cos\theta\right)$ |
| 外圈故障频率 BPFO | $\text{BPFO} = \frac{n}{2}f_r\left(1-\frac{d}{D}\cos\theta\right)$ |
| 滚动体故障频率 BSF | $\text{BSF} = \frac{D}{2d}f_r\left(1-\left(\frac{d}{D}\cos\theta\right)^2\right)$ |
| 保持架频率 FTF | $\text{FTF} = \frac{1}{2}f_r\left(1-\frac{d}{D}\cos\theta\right)$ |

> 注：工程实现需使用对应轴承型号参数（$n,d,D,\theta$）进行配置。

## 3. 信号预处理

### 3.1 包络解调处理流程

| 步骤 | 处理内容 | 目的 |
|---|---|---|
| 1 | 质量检查与去异常（缺采、饱和、突变） | 保证输入可用性 |
| 2 | 去均值/去趋势 | 去除低频漂移 |
| 3 | 带通滤波 | 保留冲击激发共振频段 |
| 4 | Hilbert 变换取包络 | 提取调幅信息 |
| 5 | 包络谱 FFT | 显化故障特征频率 |

### 3.2 关键参数建议

| 参数项 | 建议值/建议范围 | 说明 |
|---|---|---|
| 采样频率 $f_s$ | 根据传感器与目标频段配置（占位：`[待按项目填写]`） | 需覆盖共振频段 |
| 单次分析时长 | `10~60 s`（占位：`[待按项目填写]`） | 与稳定工况持续时间匹配 |
| 带通频段 | 共振区间（占位：`[f_low, f_high]`） | 建议由空载/健康数据谱图确定 |
| FFT 点数 | $2^k$（如 4096/8192） | 权衡频率分辨率与计算量 |
| 频带提峰带宽 | 特征频率 ±`Δf`（占位：`[待填写]`） | 适应转速微小波动 |

## 4. 轴承故障特征提取

### 4.1 RMS 特征
时域均方根定义为：
\[
\mathrm{RMS}=\sqrt{\frac{1}{N}\sum_{i=1}^{N}x_i^2}
\]
RMS 用于反映总体振动能量水平。

### 4.2 包络谱故障幅值特征
在包络谱中，围绕目标特征频率及其倍频提取峰值或带内能量，形成故障相关 CI：
- `ENV_BPFI_AMP`：内圈故障指标；
- `ENV_BPFO_AMP`：外圈故障指标；
- `ENV_BSF_AMP`：滚动体故障指标；
- `ENV_FTF_AMP`：保持架故障指标。

### 4.3 CI 字段定义

| 字段名 | 含义 | 单位/类型 |
|---|---|---|
| `timestamp` | 数据时间戳 | ISO8601 字符串 |
| `rpm` | 转速 | rpm |
| `RMS` | 时域均方根 | g 或 m/s² |
| `ENV_BPFI_AMP` | 包络谱内圈故障幅值 | 幅值（与谱归一化策略一致） |
| `ENV_BPFO_AMP` | 包络谱外圈故障幅值 | 同上 |
| `ENV_BSF_AMP` | 包络谱滚动体故障幅值 | 同上 |
| `ENV_FTF_AMP` | 包络谱保持架故障幅值 | 同上 |

## 5. 阈值制定及告警逻辑

### 5.1 阈值制定
对每个 CI 指标在正常数据集上统计均值与标准差：
\[
T_k = \mu_k + 3\sigma_k
\]
其中 $k\in\{\mathrm{RMS},\mathrm{BPFI},\mathrm{BPFO},\mathrm{BSF},\mathrm{FTF}\}$。

### 5.2 告警逻辑
- 超限判定：当 $CI_k(t) > T_k$ 记为一次超限；
- 触发规则：同一指标连续 3 个点超限，触发告警；
- 总告警输出：任一关键指标触发即输出 `alarm=true`。

### 5.3 工程建议：恢复滞回
为抑制抖动，建议增加恢复逻辑：
- 恢复阈值：$T_{k,reset}=\mu_k+2.5\sigma_k$（示例，可按项目调整）；
- 恢复条件：连续 `M` 个点（占位：`[建议 3~5]`）低于恢复阈值，清除告警。

## 7. 接口与部署说明

### 7.1 输入输出格式

**输入（单次执行）**
```json
{
  "timestamp": "2026-01-01T00:00:00Z",
  "rpm": "[转速数值]",
  "acceleration": "[加速度时域序列]",
  "fs": "[采样频率]"
}
```

**输出（单次执行）**
```json
{
  "timestamp": "2026-01-01T00:00:00Z",
  "ci": {
    "RMS": "[数值]",
    "ENV_BPFI_AMP": "[数值]",
    "ENV_BPFO_AMP": "[数值]",
    "ENV_BSF_AMP": "[数值]",
    "ENV_FTF_AMP": "[数值]"
  },
  "alarm": "[true/false]",
  "alarm_reason": "[超限指标列表或空]"
}
```

### 7.2 执行周期
- 固定周期：每 10 分钟执行一次；
- 每次处理一组稳定转速数据；
- 结果写入监测数据库并更新告警状态。

### 7.3 部署建议

| 项 | 建议 |
|---|---|
| 部署位置 | 车载边缘计算节点或地面服务器 |
| 运行方式 | 定时任务（10 分钟触发）+ 异常重试 |
| 配置管理 | 轴承参数、滤波参数、阈值参数可配置化 |
| 监控 | 记录输入质量、CI结果、告警事件、版本号 |

### 7.4 复杂度评估
- 单次计算主要由滤波、Hilbert 和 FFT 构成；
- 对长度为 $N$ 的数据，FFT 复杂度约 $O(N\log N)$；
- 在固定 10 分钟周期下，常规工业 CPU 可满足准实时处理要求（具体需按采样率与窗口长度实测）。

---

## 附：实施注意事项
1. 阈值统计必须基于可追溯的健康样本；
2. 不同轴承型号需独立配置特征频率参数；
3. 若转速波动超出稳定工况假设，应增加转速分层或阶次跟踪策略。
